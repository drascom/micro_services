# Microservices

This repository hosts independent projects. Each project lives on its own branch with its files at the branch root; `main` holds only this index and the shared agent rules.

## Projects

| Project | Description | Branch | README |
|---|---|---|---|
| **assistant** | Local macOS personal assistant with a SwiftUI interface and TypeScript/Pi backend. | [`assistant`](https://github.com/drascom/micro_services/tree/assistant) | [README](https://github.com/drascom/micro_services/blob/assistant/README.md) |
| **cloudstream-mac** | Mac launchers for Android streaming apps in the emulator plus a TR live TV Stremio addon. | [`cloudstream-mac`](https://github.com/drascom/micro_services/tree/cloudstream-mac) | [README](https://github.com/drascom/micro_services/blob/cloudstream-mac/README.md) |
| **diziflix** | Catalogue and playback API for the diziflix Tizen TV client. | [`diziflix`](https://github.com/drascom/micro_services/tree/diziflix) | [README](https://github.com/drascom/micro_services/blob/diziflix/README.md) |
| **inet-viewer** | Internet viewer application. | [`inet-viewer`](https://github.com/drascom/micro_services/tree/inet-viewer) | [README](https://github.com/drascom/micro_services/blob/inet-viewer/README.md) |
| **scan** | FastAPI service that processes pre-operative hair-transplant questionnaires from email attachments. | [`scan`](https://github.com/drascom/micro_services/tree/scan) | [README](https://github.com/drascom/micro_services/blob/scan/README.md) |
| **villa-bridge** | Mobile-first smart-home dashboard for Zigbee, Matter and Home Assistant. | [`villa-bridge`](https://github.com/drascom/micro_services/tree/villa-bridge) | [README](https://github.com/drascom/micro_services/blob/villa-bridge/README.md) |
