# Microservices

This repository hosts independent projects, each developed on its own branch. `main` is the project index and shared repository-management branch.

## Projects

| Project | Description | Branch | README |
|---|---|---|---|
| **assistant** | Local macOS personal assistant with a SwiftUI interface and TypeScript/Pi backend. | `assistant` | [README](https://github.com/drascom/micro_services/blob/assistant/README.md) |
| **diziflix** | Catalogue and playback API for the diziflix Tizen TV client. | `diziflix` | [README](https://github.com/drascom/micro_services/blob/diziflix/README.md) |
| **inet-viewer** | Internet viewer application. | `inet-viewer` | [README](https://github.com/drascom/micro_services/blob/inet-viewer/README.md) |
| **scan** | FastAPI service that processes pre-operative hair-transplant questionnaires from email attachments. | `scan` | [README](https://github.com/drascom/micro_services/blob/scan/README.md) |

Each link opens that project's own branch README. See [AGENTS.md](AGENTS.md) for repository and documentation rules.
