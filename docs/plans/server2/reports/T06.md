**Sapmalar / notlar**
- `llm_calls`'a README §5.1'de olmayan `background INTEGER` kolonu eklendi (bütçe yalnız arka plan çağrılarını sınırlar, admin
  çağrılarını sayar; ayırt etmek için gerekli). `complete(..., background=False)` parametresi eklendi. Bütçe kontrolü `complete`
  içinde DEĞİL: çağıran önce `budget.allowed` sorar. Modele ulaşmayan satırlar (`prompt_too_large`, `session_lost`, `pi_missing`,
  `fake_empty`) bütçeden düşmez.
- Oturum: pi kimliği `uuid5(<site>:<stage>:<attempt>)`; ilk başarılı turdan sonra `<sid>.started` işaret dosyası yazılır. İşaret var
  ama pi oturum dosyası yoksa çağrı YAPILMAZ: `Reply(ok=False, error="session_lost", session_lost=True)`, çağıran tam prompt'la oturumsuz dener.
  Token kolonları yalnız oturumlu kipte dolar (pi oturum jsonl'ındaki son `usage`); oturumsuz `pi -p` kullanım vermiyor, boş kalır.
- `gc_sessions()` (1 saatten eski oturum dosyaları) sürecin ilk `complete` çağrısında bir kez koşar (main.py'ye dokunulmadı).
  **T05 için:** `jobs_gc` içine `app.core.llm.client.gc_sessions()` çağrısı eklenmeli.
- `--offline` her iki kipte de komutta (eski `_call_pi` gibi); ek olarak `--no-skills --no-context-files --no-extensions`, cwd boş
  `DATA_DIR/llm/work`.
- `health.check` dönüşü `{ok, provider, model, error, checked_at, cached}`; model `LLM_MODEL` boşsa `PI_DEFAULT_MODEL`.
- Testler yalnız `001`+`005` migrasyonlarını geçici dizinden uygular (diğer görevlerin yarım migrasyonlarından bağımsız).

**Açık sorular:** yok. **Elle kontrol:** gerçek pi ile tek çağrı denenmedi (testler sahte; ağ kapalı).

## Denetim düzeltmeleri
- `client.complete`: pi'ye giden prompt `scrub(prompt)` (sırlar maskeli).
- `health._run`: `pi auth check` alt süreci `env=client.child_env()`, `start_new_session=True`; zaman aşımında süreç grubu `SIGKILL`.
- Sahte LLM (`DIZIFLIX_FAKE_LLM=1`) yalnız `config.test_sandbox_active()` doğruyken kullanılır.

## Kullanıcı testi düzeltmesi
- Sabit `PI_DEFAULT_MODEL` kaldırıldı: `LLM_MODEL` boşsa pi'ye `--model` VERİLMEZ (pi kendi varsayılan model + thinking ayarını kullanır).
- Görünen/kaydedilen ad (`health.model()`, `llm_calls.model`, admin): `LLM_MODEL`, yoksa pi `settings.json` (`$PI_CODING_AGENT_DIR` ya da `~/.pi/agent`; yalnız `defaultProvider`/`defaultModel`), okunamazsa `pi-default`. Sağlayıcı bilinmezse `auth check` `--provider`'sız koşar.
- pi hata koduyla çıkarsa hata `exit_code_N: <stderr ilk satırı, scrub'lı, ≤160 krk>` (admin kartında görünür). `.env.example` yorumu güncellendi.
- Testler: `DefaultModelTests` (3; sahte pi): boş modelde `--model` yok, doluysa geçer, stderr özeti hata metninde ve sırsız.
