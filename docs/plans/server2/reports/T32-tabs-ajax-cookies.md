# T32 report: source tabs over AJAX + JS-set cookies + language tabs

**Done**
- **Cookie jar (`core/fetch/cookies.py`):** `Jar` in memory only, one per operation (`PlayCtx.jar`, created in `__post_init__`; inspection `Bench.jar`). It is seeded from specs `[{name, value}]` (a literal or `now_ms`/`now_s`, generated fresh). `Set-Cookie` is stored on every hop, and each cookie goes back only to its own host/domain. `playback._send/fetch_url/post_url(jar=)`, `http.request(jar=)` and `core.fetch.get(jar=)` all take it; without a jar, `site.extra["cookies"]` seeds one. `transport.page` passes `ctx.jar`. Resolvers use `_util.send(ctx, ...)` (adds the Cookie header and passes `jar` if the transport accepts it). `follow_page` and `resolve._load_hop` use it too.
- **Map:** `fetch.cookies` (schema `FETCH_KEYS` + `check_specs`). `adapters.play_ctx` passes it to `PlayCtx.cookies`, and `site_ctx` puts it in `SiteCtx.extra`.
- **`ajax` resolver extended:** `result: auto|iframe_url|html|direct`, `cookies` (specs, also carried in the handoff), `tab_group {selector, url, method, form, json_key=data, label_from, lang}` (≤6 tabs). Each button is its own alternative. Tab labels are "<tab> · <button>" plus `sub_mode` (dublaj/altyazı/orijinal), `lang`/`language` and `audio_lang` (for dubbed). `form` accepts `attr:x|default`, e.g. querytype empty -> `alternate`. Trace: `ajax.call.answer` ("POST /ajax/service HTTP 200, JSON 'api_iframe' -> …", cookie names), then `site_hop`, then provider. On failure it shows "5xx: site çerezi eksik olabilir". `schema_notes` gives a tabbed + cookie example in the prompt schema.
- **Double `class` trap:** `_util.first_attributes(html)` keeps the first of repeated attributes, like a browser. It runs in `candidates.discover` and on tab answers. selectolax keeps the LAST one in `attributes` while CSS matching uses the first.
- **Inspection:** new actions `post` (fetch POST + xhr) and `set_cookie {name, value|now_ms}` (session only). `fetch` gets `xhr`/`headers` (allow-list only: X-Requested-With/Accept/Origin/Content-Type; cookies only via set_cookie) and `{base}`. Results list the cookie names sent. A 5xx/empty answer adds the hint "çerez eksik olabilir — document.cookie ara". `_HELP` and the A5/A6 prompts carry `AJAX_RULE`.
- **A5 (T29 rule):** `discover` plays the LLM-free rules (first 2 samples). If one plays: `evidence.llm_free_played`, and no `ask_llm`. The engine (one line) skips the LLM-first read, so there is no LLM call or investigation. Switch: `a5_player.LLM_FREE_FIRST`. `parse_reply`: `result.cookies` / `result.fetch.cookies` -> `cookies` on the ajax resolvers.
- **Crawl/playback (T28):** an ajax alternative is stored as `kind: ajax` (handoff = element tokens/form + cookie SPECS; never a cookie value or the answer URL). No AJAX runs during the crawl. At playback, `as_raw` re-runs the hand-off with a fresh jar. `update_from_play` writes it the same way.
