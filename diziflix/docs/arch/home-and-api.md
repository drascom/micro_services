# Ana ekran düzeni, API/sözleşme koruması, cache, ayarlar, admin

> Bu bölüm CLAUDE.md'den taşındı (2026-10-02). Metin birebir taşınmıştır; kısa harita ve kurallar `diziflix/CLAUDE.md`'dedir.

## `cache.py`, `settings.py`, `routers/`, `db.py`

- `cache.py` - katalog RAM'de `Snapshot`; her istek buradan okur. APScheduler `CACHE_TTL` ile yeniler; ayrıca her 60 sn'de bir ingest "tick"i (`autoscan.py`) admin ayarlarına göre vadesi gelen siteleri tarar. `cache.refresh()` snapshot'ı baştan kurar (tek tutarlı okuma görünümü; önce başlayan derleme sonra başlayanı ezmez). Tarama ORTASINDA da yenilenir: `library/ingest.py` `set_progress_hook(fn)` kancası (`cache.start()` `cache.refresh_progress`'i bağlar, CLI'da kanca yok) başlıklar commit edilince (`titles`), her dizi envanteri yazılınca (`inventory`), TMDB sezon aşamasından sonra (`seasons`) çağrılır; `titles` dışındakiler `INGEST_REFRESH_MIN_INTERVAL` (20 sn) debounce'lu, aynı anda tek yenileme, kanca hatası ingest'i bozmaz; tarama sonundaki tam yenileme aynen sürer
- `settings.py` - admin panelinden yönetilen kalıcı çalışma-zamanı ayarları (`data/ops_settings.json`): site başına otomatik tarama aç/kapat + aralık, `heal_autoapply`, `tmdb_auto`, `tmdb_types`. `.env` (`INGEST_SITES`, `INGEST_INTERVAL`, `SCRAPER_HEAL_AUTOAPPLY`) artık yalnızca VARSAYILAN; panelden kaydedilince panel kazanır, restart gerekmez. `llm_health.py`: heal LLM hesabı durumu (`pi auth check`, 60 sn önbellek)
- `routers/` - health, profiles, boot (kademe 1), rows (kademe 2, lazy), detail (kademe 3), streams (+`/api/playback-report`), subtitles (`GET /api/subtitles/<id>.vtt`, soft altyazı vekili), progress, mylist, search, images (`/img`), catalog (`/api/catalog`, `/api/genres`), ops (`/admin` tek sayfa panel, `/api/ops/*`; video-sources/identities bakım uçları `/api/admin/*`), ops_settings (`/api/ops/settings` GET/PUT, `/api/ops/llm/health` GET/POST), ops_tmdb (`/api/ops/tmdb/backfill|status|preview`), ops_library (`/api/ops/library` admin Kütüphane listesi + `/{id}/videos`)
- `db.py` - sqlite3, çağrı başına bağlantı, WAL; şema `SCHEMA` listesi + `_migrate` (additive). Tablolar: profiles/progress/mylist/continue_hidden, library_items, source_items, library_lists, field_provenance, external_ids, catalogue_aliases, identity_reviews, video_sources, playback_attempts, library_seasons, library_episodes (TMDB sezon posteri + bölüm başlık/özet/tarih/süre/still; kaynak alanları ezilmez, okurken birleşir)

## Hata zarfı, admin paneli

- Hata zarfı: `{"error":{"code","message"}}` (`errors.py`); dev yardımcıları her uçta `?delay=<ms>`, `?fail=1` (`main.py` middleware)
- Auth yok (admin dahil, kapalı LAN); token kaldırıldı. Profil = seçim, parola yok. Admin: `static/admin/` (vanilla, "Olay defteri": kaynak sağlık şeridi + birleşik `GET /api/ops/events` feed + olay detayı; prototipler `static/admin-next/`), aktif işler bellek içi (`scraper/state.py`), run/heal/tmdb geçmişi `data/scraper_state/_ops.json` (her biri son 200). Admin "Ayarlar" sekmesi (`#settings`, `settings.js`): otomatik tarama (site başına aç/kapat, aralık, sonraki tarama, "Şimdi tara"), heal autoapply, TMDB zenginleştirme kartı (anahtar rozeti, kapsam, otomatik anahtarı, tür kutuları, önizleme/uygula), LLM hesabı durumu/"Test et"; değişiklik anında kaydolur. Admin "Kütüphane" sekmesi (`#library`, `library.js`): merkezi kütüphane grid/liste, süzgeç (site çoklu, kırık durumu, tür, TMDB, arama, sıralama, sayfa 50), her öğede **K/T** rozeti = kırık/toplam `video_sources` (T: devre dışı hariç; K: `broken`; `suspect` ayrı `?N`, K'ya dahil değil; yeşil hepsi sağlam, sarı kısmi, kırmızı hepsi kırık, gri `0/0`) ve rozet/detayda kaynak listesi

## Ana ekran düzeni (`homelayout.py`)

- **Ana ekran düzeni** `app/homelayout.py` (düzenin TEK yeri, `layout(profile_id)`; ileride izleme alışkanlığına göre tür satırları buraya girer): slider (`heroes[]`: 3 dizi + 3 film, dönüşümlü, `has_backdrop` + oynatılabilir zorunlu), `continue`, `trending_series` ("Haftanın Trendleri · Diziler"), `series` ("Tüm Diziler"), `trending_movies` ("Haftanın Trendleri · Filmler"), `noteworthy_movies` ("Dikkate Değer Filmler"), `movies` ("Tüm Filmler"), `mylist` (yalnız doluysa, sonda). Env: `HOME_LAYOUT`, `HERO_SERIES`/`HERO_MOVIES` (3/3), `HOME_ONLY_READY` (1: ana ekran yalnız `availability.state=ready` başlıkları gösterir, `continue`/`mylist` istisna; arama/katalog etkilenmez), `CLASSIC_MIN_RATING` 7.5, `CLASSIC_MIN_AGE_YEARS` 15. "Tüm Diziler/Filmler" = o türün TÜM başlıkları (`added_at` azalan). `trending_*` = sitelerin `trending` rol listeleri (tür filtreli) + `trend_score` ile ≥20'ye doldurma. `noteworthy_movies` = site listeleri + klasikler (oynatılabilir film, puan ≥7.5, yıl ≤ bu yıl-15; klasik puan/slider/trend doldurmasına GİRMEZ). `trend_score`: trend listesi `50-konum`, diğer rol listeleri 20'şer (≤40), `added_at` ≤14 gün +15/≤45 gün +8, yıl ≥ bu yıl-1 +10, son bölüm ≤14 gün +15, puan `(r-6)*5` (≤20), takipçi log (≤10). Rol listeleri `latest_series/latest_episodes/latest_movies/featured` ARTIK satır değil PUANLAMA SİNYALİ; eski satırlar (`new_series`, `new_episodes`, `latest_*`, `trending`, `new_movies`, `genre_*`) ana ekranda yok ama `/api/row/<id>` ile çalışır. `/api/catalog` ek `sort=trending|popular`. İstemciler satır/slider'ı GENEL çizer; kimliğe bağlı özel durumlar yalnız `continue`, `series`/`movies` ("Tümü" kartı), `mylist`
