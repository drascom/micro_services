# Akışlar: çözümleme önbelleği, akış/HLS vekili, tanı, ses/altyazı izleri

> Bu bölüm CLAUDE.md'den taşındı (2026-10-02). Metin birebir taşınmıştır; kısa harita ve kurallar `diziflix/CLAUDE.md`'dedir.

## Çözülmüş yük önbelleği

- **Çözülmüş yük önbelleği** (`library/videos.py` `resolve_source` + `library/streamlife.py`): yükte `valid_until` = `min(akış URL expiry ipuçları) - RESOLVE_CACHE_MARGIN` (300); ipucu yoksa `RESOLVE_CACHE_TTL` (900); üst sınır `RESOLVE_CACHE_MAX_TTL` (6 sa); sağlayıcı/tarif/json_api `cache_ttl` (60..86400) açık süre verir. İpuçları: `expires/expire/exp/e` (yalnız MAKUL epoch; göreli sayı yok sayılır), `X-Amz-*`, Azure `se`, Akamai `~exp=`, yolda `/expire/<epoch>/`. `valid_until - now < RESOLVE_REFRESH_AHEAD` (600) ise yük döner + ARKA PLANDA yenilenir (sağlık kolonlarına dokunmaz, kaynak başına tek-uçuş). Oynatma hatası (`aborted/offline/autoplay` hariç) ve `retry` o kaynağın yükünü siler. Eski yükler (`valid_until` yok) eski kuralla geçerli, `RESOLVER_VERSION` artmadı. Admin `last_resolver`'da `from_cache`/`valid_in`; `/api/streams` sözleşmesi değişmedi. Test: `tests/test_resolve_cache.py`

## Akış vekili

- **Akış vekili** `app/streamproxy.py` + `routers/stream_proxy.py` (`GET|HEAD /api/stream-proxy/<token>`): UA'ya bağlı imzalı mp4 URL'leri (OK.ru `srcAg=CHROME`: Chrome olmayan her oynatıcı 400 alırdı) için akış `request_headers` (yalnız User-Agent/Referer/Cookie/Origin) taşır; OK.ru provider `fetch.USER_AGENT`'ı koyar, `player_page`/`json_api` `stream_headers`. `/api/streams` bu mp4 akışlarının `url`'sini `<taban>/api/stream-proxy/<HMAC token>` yapar ve `proxied:true` koyar (embed vekillenmez, HLS yalnız aşağıdaki "Vekil genişletmesi" nedenleriyle; `request_headers` yanıta girmez; `resolved_payload` doğrudan URL tutar; `RESOLVER_VERSION` 7). Taban: `STREAM_PROXY_BASE_URL` (boş; doluysa her istemciye o) -> `X-Forwarded-Proto/Host`/`Forwarded` -> `Host`+şema (LAN istemcisi tünelden dolaşmaz; token'da taban yok). Token `STREAM_PROXY_SECRET` (boşsa `data/stream_proxy.key` 0600), TTL `STREAM_PROXY_TTL` 6 sa (403/410), `netguard` her hop'ta (≤3 yönlendirme), `Range/If-Range` aktarılır, `STREAM_PROXY_MAX` (8) üstü 503. Sözleşmede `streams[].proxied` bool zorunlu

## Vekil genişletmesi (HLS + öğrenilmiş vekil + hata tanısı)

- **Vekil genişletmesi (HLS + öğrenilmiş vekil + hata tanısı)** Karar `streamproxy.proxy_reason(stream, headers, learned=)` (`/api/streams` `streams[].proxy_reason` = `ua|ip|recipe|learned|env`, yalnız `proxied:true`'da; sıra bu): `ua` = `request_headers`'lı dosya (HLS bunun dışında), `recipe` = recipe anahtarı `stream_proxy: true` (`recipes.py`; akışlara iç işaret `stream_proxy`, yanıta girmez), `ip` = googlevideo `videoplayback` + `ip=`/`ipbits=`, `learned` = `video_sources.proxy_required=1`, `env` = `STREAM_PROXY_FORCE=1` (tüm mp4/hls) / `STREAM_PROXY_HOSTS`. HLS URL'si `<taban>/api/stream-proxy/<token>/index.m3u8` (`type:"hls"` aynı; rota `/{token}` ve `/{token}/{name:path}`, ad yok sayılır): token yük `{u,h,exp,k:playlist|segment|key,g:grup}`, `app/hlsproxy.py` listeyi çekip (≤`STREAM_PROXY_PLAYLIST_MAX`, `#EXTM3U` şart; `.txt` olabilir) TÜM URI'leri (bölüm satırları, KEY/MAP/MEDIA/I-FRAME `URI=`, master çocukları, göreli çözümlenir) yeni token'la yazar; Cookie token host'u dışına gitmez; limit AKIŞ (grup) başına `STREAM_PROXY_HLS_MAX` (24) + `STREAM_PROXY_QUEUE_WAIT` (8 sn) kuyruk sonra 503; dosya vekili `STREAM_PROXY_MAX` aynen. `library/streamdiag.py`: `/api/playback-report` (+isteğe bağlı `detail` ≤120) başarısızlığında (`aborted/offline/autoplay` hariç) ARKA PLANDA (kaynak başına 10 dk'da bir, eşzamanlı 2, `STREAM_DIAG*`) akışı sunucudan yoklar -> `video_sources.last_diag` (JSON ≤600 B: code http ct ms at note) `reachable|forbidden|not_media|gone|timeout|expired|ip_bound|hls_unsupported_browser|server_blocked|unreachable`; düz istek reddedilip akışın kendi başlıklarıyla/IP ile erişiliyorsa `proxy_required=1` + çözümleme önbelleği silinir (sonraki `/api/streams` `learned`); vekilli yoklama da başarısızsa `server_blocked`. Tüm akışları HLS olan kaynakta `engine:html5` + masaüstü Chrome/Firefox/Edge UA = `hls_unsupported_browser`: hata KAYNAĞA SAYILMAZ (suspect/broken yok, bağlantı korunur). Admin `/api/ops/library/{id}/videos` her kaynakta `diagnosis{code,note,at,http,proxied,proxy_reason,proxy_required}` + `library.js` rozeti; K/T aynı. Testlerde `STREAM_DIAG=0` (`_sandbox.py`). Testler `tests/test_stream_hls_proxy.py`, `tests/test_stream_diag.py`

## Ses/altyazı izleri

- Ses/altyazı izleri: `library/tracks.py` (akış başına `variant_id`/`audio_lang`/`sub_mode`/`hard_lang` + `sub_known`/`site_lang_hint`/`mirror_of`, kökte `subtitles[]`+`audio[]`; yalnızca EKLEME, eski alanlar aynı), `subtitles.py` (kaynak kaydı `data/subcache/<id>.src`, indirme `fetch.fetch_limited` — host allow-list `srt.vidmoly.*` + `SUBTITLE_HOSTS`, her yönlendirmede denetim, 1 MB/5 sn — SRT→VTT + zaman normalizasyonu, `data/subcache/<id>.vtt`, ölü kaynak 404), `langs.py` (dil kodu/Türkçe ad); `providers/vidmolly.py` `subtitle_tracks()` gömme sayfasının JW Player `tracks` dizisini okur (`thumbnails` atlanır, biçim değişirse yalnız altyazı kaybolur), `RESOLVER_VERSION` 5. İstemci: `tizen-client/js/{subs,tracks}.js` + `js/ui/tracks_panel.js` ("Ses ve Altyazılar" paneli, Sarı tuş/Aşağı ok; motor-bağımsız DOM altyazı katmanı; tercih `dz_pref_sub_<profil>`/`dz_pref_audio_<profil>`)
- Soft altyazı fixture'ları `server/tests/fixtures/vidmolly_*` (imza/IP sansürlü); ağsız testler `server/tests/test_subtitles.py`, istemci `tests/{subs,tracks,player_tracks}.js`
