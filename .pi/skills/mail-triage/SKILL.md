# Mail triage

- `propose` first, without asking (no change; delete etc. = `query`+`act`). Spoken reply: 2-3 sentences; numbers only the level counts; gist of the 🔴/🟠 sender groups, never ids or numbers; a missing label in one sentence with its exact name; end with "Uygulayayım mı?" and stop. Groups only if asked.
- `apply` with `confirm_token` only after the user's reply confirms. `purge_junk` moves `Gereksiz` mail to Trash the same way (ask first).
