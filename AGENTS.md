# AGENTS.md

Guidance for coding agents in `drascom/micro_services`.

- This public repository is for releases only: `main` (README), `gh-pages` (static site), GitHub releases and their tags. It holds no project code.
- Release assets and tags are published by scripts in the private source repositories. Do not create releases or tags here by hand.
- Do not commit code, project branches, build outputs or private details (paths, hostnames, IPs, credentials) to this repository.
- Never force-push or rewrite `main` or `gh-pages`.
