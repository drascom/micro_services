Privacy Policy

Last updated: 2026-10-11

Personal Assistant is a personal voice assistant that runs on its owner's own device or home server. It is used only by its owner (drascom) with his own Google account. This policy explains how it handles Google user data.

Google data accessed

The app requests a single Google scope: https://www.googleapis.com/auth/gmail.modify. It is used only to:

  • read the owner's own inbox messages: sender, subject, Gmail's short snippet (preview), Gmail category labels and the authentication headers (Authentication-Results) used to verify the sender. The message body is not sent to the classifier;
  • add and remove labels (for example starred, important, "Sonra Oku", "Gereksiz") and mark messages as read;
  • move messages labelled as junk to Trash.

The app never sends email and never permanently deletes messages. Actions can be undone from within the app.

How data is processed and stored

  • All processing happens on the owner's own device or server. There is no separate backend operated by the app.
  • The OAuth client credentials and tokens are stored in the device's secure storage (macOS Keychain), never in configuration files or logs.
  • Classification is done by a local language model running on the same device by default. If the owner chooses a remote LLM provider for a request in the app's settings (for example an OpenAI subscription model), the sender name and address, subject, snippet and Gmail category of the messages being sorted may be sent to that provider for that request. The message body is never sent.
  • The action log stored on the device contains only message IDs, priority levels and labels — no message content.

Sharing

Google user data is not shared with third parties (except the optional, owner-selected LLM provider described above), is not sold, and is not used for advertising or to train AI/ML models.

Google API Services User Data Policy

Personal Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from your Google Account → Security → Third-party access (myaccount.google.com/connections), or with the "Disconnect" button in the app, which revokes the token and deletes it from the device.
